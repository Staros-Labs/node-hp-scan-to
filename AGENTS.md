# Repository Guidelines

## Working Rules

- Work from a git worktree when making repo changes.
- Do not use emojis in commits, pull requests, comments, or docs.
- Do not mention assistant product names in commits, pull requests, comments, or repo files. Use role-based terms such as `builder` or `reviewer` if needed.
- This repo uses `develop` as the integration branch and `master` as the production branch.

## Branch Guidance

- Target `develop` for ongoing feature and maintenance work.
- Treat `master` as the stable production branch.
- Update workflow or README guidance in the same change when branch behavior changes.
